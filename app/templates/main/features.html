Feature Architecture

Comprehensive Lab Suite

Explore the specialized engines powering WebPulse's website quality and performance diagnostics.

Secure Archive Ingestion

Phase 2 Engine

A dedicated archive validation pipeline verifies every uploaded project. It computes compression ratios, enforces strict size thresholds, normalizes file paths to neutralize Zip Slip vulnerabilities, and stores files in private storage directories completely detached from public web servers.

  • Multi-tier file extension & MIME type verification
  • Path traversal and symlink rejection
  • Atomic extraction with rollback on failure

Rule-Based Static Analysis

Phase 3 Engine

Inspects project files using Beautiful Soup and AST parsers. Rather than broad regex guesswork, the static analyzer performs AST parsing to detect missing accessibility attributes, duplicate script references, render-blocking stylesheets, and unoptimized raster assets.

  • Line-level error attribution and evidence snippets
  • Severity tiers: Critical, High, Medium, Low, Informational
  • Confidence ratings differentiating heuristics from definitive issues

Cytoscape Dependency Mapping

Phase 4 Engine

Renders interactive, zoomable network graphs illustrating file references throughout the project. See how HTML documents import CSS stylesheets, how CSS requests custom web fonts or background SVGs, and identify dangling broken references immediately.

  • Color-coded nodes by file category (HTML, CSS, JS, Image, Font)
  • Red highlight edges indicating broken local paths
  • Node selection with detailed metadata inspector

Playwright Sandbox Testing

Phase 6 Engine

Executes project entry points in a sandboxed headless Chromium instance. Captures real navigation timings (DOM Content Loaded, Load event), network request waterfalls, HTTP status codes, failed asset fetches, and JavaScript console exceptions.

  • Strict process isolation with CPU and execution time limits
  • Resource timing waterfall chart via Chart.js
  • Transparent lab measurement disclosures without fake scores
