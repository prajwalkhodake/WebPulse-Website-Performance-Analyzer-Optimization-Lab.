Engineered For Depth, Not Generic CRUD

Every analysis metric in WebPulse is backed by verifiable code evidence or sandboxed browser measurements.

Static Analysis Engine

Parses HTML, CSS, JavaScript, and assets using Beautiful Soup and AST tokenizers. Pinpoints missing alt tags, render-blocking scripts, and oversized assets with line-level accuracy.

Cytoscape Dependency Graph

Maps relationships between HTML entry points, imported stylesheets, scripts, fonts, and images. Interactively identify orphaned assets and circular references.

Browser Sandbox Testing

Launches headless Chromium via Playwright in an isolated execution sandbox. Captures real resource timings, navigation events, JavaScript console errors, and Core Web Vitals.

Version Diffs & Reports

Upload revised archives to inspect before-and-after improvements. Verifies whether recommendations were applied, tracking resolved issues, regressions, and byte savings.

Security Architecture

Safe Handling of Untrusted Archives

Uploaded ZIP files are untrusted by definition. WebPulse enforces strict multi-layer defense before extracting any content:

  • Anti-Zip-Slip: Normalizes every path and prevents directory traversal (../) and absolute root paths.
  • Zip Bomb Mitigation: Enforces 50MB uncompressed ceiling and 100:1 compression ratio limits.
  • Isolated Storage: Files are stored in private directories outside public static serving paths.
  • No Arbitrary Code Execution: Server never executes uploaded shell scripts, npm packages, or server-side binaries.
